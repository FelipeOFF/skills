# `lib/` folder tree — layered clean architecture (rx_notifier MVVM)

Reference target tree for a new app generated by `/af-bootstrap`. `lib/` is
organized **by layer, not by feature** — except `feature/` and `di/`, which are
sharded internally per feature. Every cross-layer reference is an
abstraction (`AbstractUseCase`, `IExampleRepository`), never a concrete class.

Rename anchors: `feature/<name>`, `Example`, `Item`, `Feature` get renamed to
the real feature/entity. Package is `app`; all imports are `package:app/...`.

```
lib/
  main.dart                       DI bootstrap order, then runApp(AppWidget())
  app_widget.dart                 MaterialApp.router + ThemeExtensions + go_router

  feature/                        UI, sharded per screen (the ONLY by-feature top layer)
    feature/
      page/feature_page.dart      View: StatefulWidget + BaseState<…, FeatureController>
      controller/
        feature_controller.dart   ViewModel: extends BaseController, RxNotifier fields
      di/feature_binding.dart      registers the Controller as a FACTORY
      navigation/feature_navigation.dart   per-feature BaseNavigation routes
    home/  detail/  settings/  auth/  profile/   one shard each

  domain/                         use cases + the error model (the inner ring)
    abstract_use_case.dart        AbstractUseCase<PARAM, RESULT> — the Either funnel
    abstract_stream_use_case.dart stream variant, Either per event
    app_error.dart                sealed AppError: Default/Logout/NetworkException/UnknownException
    example/get_example_use_case.dart   one verb = one class: <Verb><Noun>UseCase

  repository/                     interface + impl per sub-domain
    example/
      i_example_repository.dart   abstract interface, `I` prefix
      example_repository.dart     concrete impl: client + cache, maps DTO <-> envelope

  service/                        typed transport facades over the gateway
    client/
      logged_client.dart          auth + refresh interceptors (via hook)
      non_logged_client.dart      no auth
    endpoint/endpoints.dart       endpoint path constants

  gateway/                        Dio base: options, interceptors, SSL pinning, HTTP/2
    abstract_gateway.dart
    interceptor/  exception/  model/  urls.dart
    exception/dio_exception_extension.dart   DioException.asAppError()

  model/                          DTOs (freezed + json_serializable), cross-cutting
    example/
      req/example_request_dto.dart
      res/example_dto.dart
    response_dto.dart             generic envelope ResponseDTO<T>.fromJson

  cache/                          read-through TTL cache (drift-backed)
    fu_cache.dart                 FuCache<T> decorator
  database/                       persistence (drift)

  di/                             get_it wiring — one AbstractBinding per layer/feature
    abstract_binding.dart         AbstractBinding.binding(GetIt it)
    app_di.dart                   AppDI.setupDI(): ordered list of bindings
    environment/  database/  gateway/  service/  repository/  domain/

  common/                         base mixins, utils, extensions, messages
    base/
      base_controller.dart        BaseController + exec ladder mixin (execSingle/execCallback)
      base_state.dart             BaseState<W, C> — wires View to its Controller

  design_system/                  ThemeExtension token palettes + context extensions
  navigation/                     AppRouter route enum + go_router config
  configurations/                 Environment (server url, flags)
  generated/  res/                codegen output + assets (never hand-edited)
```

`test/` mirrors `lib/` paths one-to-one; test files are named `*_test.dart`.

## Layer dependency rule (inward only)

```
feature/ (View + Controller)
   ▼  Controller calls use cases via execSingle / execCallback
domain/  (AbstractUseCase, AppError)
   ▼  depends on the repository INTERFACE only
repository/  (IExampleRepository  ←  ExampleRepository impl)
   ▼  orchestrates transport + persistence
service/client/ + cache/ + database/
   ▼
gateway/  (AbstractGateway → Dio)
```

`model/` and `di/` are cross-cutting and may be referenced from any layer.
A layer NEVER imports a layer above it.
